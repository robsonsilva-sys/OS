- **Sempre publicar:** ao concluir qualquer alteração neste projeto, faça `git add`, `commit` com mensagem descritiva e `push origin main` automaticamente. Não é necessário pedir confirmação para subir na `main`.
- O site é publicado via GitHub Pages a partir da branch `main`, pasta `/ (root)`; o deploy é automático a cada push.
- Prefira responder em português.
- Projeto Supabase: `zubrrdburxbdduksfhxr.supabase.co`. O schema está em `supabase/schema.sql` e o keep-alive em `.github/workflows/supabase-keepalive.yml`.
- Após alterações, valide no navegador e confirme que o build do GitHub Pages terminou (`built`) antes de dar o trabalho como concluído.
